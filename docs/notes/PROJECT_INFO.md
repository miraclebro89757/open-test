## For Your Own Projects

When using this repository as a template for your proprietary projects:

1. **Artifact Organization**: Store project artifacts in a visible folder structure:
   ```
   ~/Desktop/ProjectName/
   ├── 需求文档.md           (Requirement Document)
   ├── ProjectName/          (Artifacts Folder - matches product/project name)
   │   ├── design/
   │   ├── implementation/
   │   └── reports/
   └── ...
   ```

2. **File Organization**: 
   - Place requirement documents in the parent directory
   - Create a dedicated folder matching your project name for artifacts
   - Do NOT use hidden directories (they will be excluded)

3. **Privacy**: 
   - Keep sensitive projects in private repositories
   - Remove specific company/product names when sharing open-source versions
   - Use generic naming conventions for public examples
